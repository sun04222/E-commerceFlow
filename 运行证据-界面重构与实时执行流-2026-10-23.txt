七、版本控制（本轮的每一步都有对应提交）
----------------------------------------------------------------
本机没有 git 可执行文件、网络被限制装不了，所以本轮用自写的零依赖 Git 实现
（.devtools/git.mjs：blob/tree/commit 对象 + zlib + SHA-1 + refs + 二进制 index）。
可信度来自两道自检：
1) 拿本机另一个真实仓库的 **382 个 loose object** 当基准（253 blob / 110 tree / 19 commit）：
   逐个「解压 → 重算 SHA-1」并对 tree/commit 做「解析 → 重新序列化 → 比哈希」，
   **不一致 0 个**（序列化只要差一个字节——时区、空行、排序——哈希就对不上）。
2) 对自己写的仓库 fsck：类型合法、长度自洽、名字等于内容哈希。
   最新的提交后：本仓库自检 97 个对象（blob 65 / tree 26 / commit 6）· 不合格 0
   工作区干净（status 无输出）。
——第 1 项是必须的：只验「自己写、自己读」会漏掉写入口的错（本轮就漏过一次：
  写对象时忘了拼 `type len\0` 头，对象名对、内容不对，只有 fsck 才拦得住）。
