────────────────────────────────────────────────────────────────────────────────
一、先摆事实：三种形态各自的真实要求（全部现场复查，非推断）
────────────────────────────────────────────────────────────────────────────────

$ ls -d node_modules
→ node_modules: 不存在

$ grep -nE '"(dependencies|devDependencies)"' package.json
→ （无输出）dependencies / devDependencies: 均不存在

$ grep -n '"engines"' -A2 package.json
→   "engines": {
        "node": ">=22.18.0"
      }

$ grep -c -E '(src|href)="//' demo.html      # 协议相对外链
→ 0

$ grep -c -E 'https?://' demo.html           # 任何 http(s) 字样
→ 0

含义：
  · `npm install` 三种形态都不需要 —— 无依赖声明、无 node_modules，
    靠 Node 22.18+ 原生 TypeScript 类型剥离直跑 .ts。
  · `demo.html` 零外链、零 http(s) 字样 —— 它在结构上就不可能去连外面。

────────────────────────────────────────────────────────────────────────────────
三、跨设备：桌面端服务能不能被别的设备访问（实测否）
────────────────────────────────────────────────────────────────────────────────

$ grep -n "listen(" desktop/server.mjs
→ 554:server.listen(PORT, "127.0.0.1", () => {

$ netstat -ano | grep -E ":8787\b"
→   TCP    127.0.0.1:8787         0.0.0.0:0              LISTENING       79600
    （只有 127.0.0.1，没有 0.0.0.0）

本机局域网 IP = 10.97.43.176

$ curl -s -o /dev/null -w "http=%{http_code}" http://10.97.43.176:8787/
→ http=000          （000 = 连不上）

$ curl -s -o /dev/null -w "http=%{http_code}" http://127.0.0.1:8787/   # 对照
→ http=200

结论：桌面端服务只绑回环地址，只有本机能开。别的设备（同一局域网也不行）连不上。
      这是有意的：演示工程不该在局域网上裸奔。要在别的设备上看，走单文件版。

────────────────────────────────────────────────────────────────────────────────
四、三形态对照（本文件实测结论汇总）
────────────────────────────────────────────────────────────────────────────────

| 形态                | 要 Node 吗        | 要 npm install 吗 | 要联网吗              | 能拷到别处吗               |
|---------------------|-------------------|-------------------|-----------------------|----------------------------|
| demo.html 单文件版  | 不要              | 不要              | 不要（零外链）        | 一个文件，拷到哪都行       |
| 桌面端服务版        | 要 Node ≥ 22.18   | 不要（零依赖）    | 规则不要；模型判定要  | 要带整个项目目录，且只本机 |
| 命令行版            | 要 Node ≥ 22.18   | 不要              | 规则不要；模型判定要  | 要带整个项目目录           |

一句话：**要 Node 的只有服务端/命令行两形态；`npm install` 三种形态都不需要；
联网只有「模型判定」那一档需要。要发给别人，给 demo.html 这一个文件就够。**

五、复现命令（照抄可重跑）
